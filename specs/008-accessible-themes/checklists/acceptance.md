# Acceptance Checklist

- [x] Blue, red, green and orange are named free themes.
- [x] Premium is discoverable and fail-closed without entitlement.
- [x] Current selection is announced and not color-only.
- [x] Token contrast gates pass.
- [x] Keyboard activation and focus visibility are proven automatically.
- [x] Reduced-motion avoids view-transition animation.
- [x] 320 CSS px and 400% zoom are manually reviewed or explicitly blocked.
- [x] Screen-reader behavior is manually reviewed or explicitly blocked.
- [x] No authorization or political meaning is derived from theme.
- [x] No external effect, billing or storage is introduced.
