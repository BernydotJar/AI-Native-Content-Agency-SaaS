# CampaignOS Media Generation Lab — local-first, guarded effects

## Decision

Keep the public marketing website on static zero-cost hosting.
Do not introduce Firebase Functions, a cloud GPU, paid video API calls, a database,
paid ad delivery or API secrets into its frontend. Producing local videos avoids
per-request vendor fees but still consumes hardware, electricity, time, disk and
possibly model license entitlements. The runtime release policy and Greenlight
remain independent requirements.

| Provider | Fit | Current safe boundary |
| --- | --- | --- |
| FreeVideo + ComfyUI | Local T2V/I2V/reference-guided generation, quality ladder | First local candidate. Install a compatible GPU/Mac worker, pin a real exported workflow and review model weight license. |
| H3ddle | Apple Silicon native studio, editing, sound and export | Operator/editor option. Browser-only bridge cannot control native SwiftUI windows. |
| HeyGen BYOK | Presenter, narration, localization and templates | Optional paid API; key must stay server-side. An imported key is not spending authorization. |
| Cloud Sandbox Computer Use | Assisted browser-hosted generators | Chrome/Edge only with native per-action approval. No arbitrary native desktop automation. |

Open-source app licenses do not imply that downloaded diffusion model weights
permit unrestricted advertising or that computation itself is free.

## Evidence of the two local video experiments

This branch creates **two original animated storyboards** using Python/Pillow
and FFmpeg on CPU. They are not generated by FreeVideo, HeyGen, H3ddle, Runway,
or any generative video model. They must never be represented as such.

**Spaghetti motion experiment:** an illustrated fictional adult, spaghetti,
plate, and moving fork/hand. Inspired by the famous early "Will Smith eating
spaghetti" AI-video benchmark concept. The actual test does not mimic an
identifiable celebrity or falsely imply endorsement.

**CampaignOS brand experiment:** dark cinematic brand concept with eight
connected stations, a moving pipeline pulse, and a readable message.

Both exported as MP4 720 x 1280, H.264/yuv420p/AAC, 24 fps, 6 seconds,
144 frames; no paid provider, API key or GPU use. These are **previews**, not
final 1080p footage or evidence of generative model realism.

Generated outputs and contact sheets remain gitignored:

    artifacts/media-lab/generated/

To rebuild:

    python3 -m venv /tmp/campaign-media-qa-venv
    /tmp/campaign-media-qa-venv/bin/pip install Pillow==12.0.0
    PYTHON_BIN=/tmp/campaign-media-qa-venv/bin/python \
        bash scripts/media-lab/run_quality_gate.sh

Requires system ffmpeg and ffprobe. To check a real model output:

    python3 scripts/media-lab/check_video.py path/to/clip.mp4 \
      --orientation vertical --tier final \
      --contact-sheet /tmp/contact.png \
      --json-out /tmp/video-qa.json

Preview mode requires a short edge >= 720px; final mode requires >=1080px.
The checker inspects codec, frame rate, aspect ratio, duration, streams,
decodes all frames and audio, computes SHA-256, flags long blackouts/freezes,
measures approximate audio levels and creates a contact sheet.

A technical PASS only means this file is deliverable, not that its
creative quality is acceptable.

## Quality release rubric (human-reviewed, 0–100)

| Category | Weight | Inspection |
| --- | ---: | --- |
| Identity, anatomy, temporal/object continuity | 25 | Face, fingers, fork, spaghetti, camera, no morphing/teleporting. |
| Prompt adherence and visible story progression | 20 | Correct action sequence and understandable message. |
| Creative art direction and lighting | 20 | Color grade, contrast, coherent shadows and brand visual quality. |
| Cinematography and pacing | 10 | Stabilized motion, intentional cuts and readable hook. |
| Brand typography / mobile-safe framing | 10 | Correct text, no invented logos, legible at phone size. |
| Audio synchronization and mix | 10 | Intentional bed, dialogue sync, no clipping, acceptable loudness. |
| Rights, provenance, AI disclosure | 5 | Permission for face/voice/media and commercially valid model license. |

**Minimum release threshold is 85/100**, plus zero critical defects in
identity, hand/object motion, misinformation, publication permission,
voice/likeness consent, or rights. Another person reviews full video at
native resolution and on a phone. Human Greenlight and product release
authorization remain required regardless of score.

For model quality experiments, save the exact prompt, seed, checkpoint SHA,
workflow JSON, model license, hardware and generation duration. Preview first;
reject failures in anatomy/object continuity instead of merely upscaling
them. Compare at least two independent seeds and select the best.

## BYOK architecture boundary for HeyGen

1. Store a tenant-scoped encrypted API key on the server, never as a Vite
   environment variable or exposed through a public static website.
2. Bind tenant, campaign, render recipe, exact input hashes, approved
   avatar/voice IDs, idempotency key and Greenlight fencing token.
3. Query price/quota and enforce cost ceiling **before submission**.
   A zero-cent ceiling rejects any billable generation.
4. Use a restricted HTTPS endpoint allowlist, bounded payload size/timeout
   and server-side status polling or verified signed webhooks.
5. Record durable effects, provider request IDs, actual charges and output
   hashes. Reconcile retries/cancellation; do not duplicate paid jobs.
6. Obtain rights to likeness/voice, audit privacy terms, retention,
   data processor obligations and model/output usage rights.
7. Pass the actual MP4 through technical and independent creative review.

The current product has an independent reviewed-disabled video provider
catalogue in development. This QA worktree intentionally does not alter
its interfaces or its control-plane authority.

## Current environment limitation

The Cloud Sandbox Linux workstation has roughly 8 GiB RAM, no
visible NVIDIA GPU, and no reachable ComfyUI endpoint on loopback or the
Docker host bridge. The native Mac is not exposed for GPU inference
through the current browser-only Computer Use tools. Thus **no genuine
MiniMax H3 diffusion run was performed** in this experiment. A Mac or
other sufficiently provisioned GPU worker with operator access is
required for that later benchmark.

All demonstrated costs here are **zero cloud/API charges**. The generated
videos are original local graphic animations and require human
creative review before any marketing publication.
